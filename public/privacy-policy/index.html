Privacy Policy

This Chrome extension is designed to visualise the textual structure of a webpage as a 3D word network.

Data Access

The extension accesses the URL and text content of the currently active webpage only when the user opens the extension to generate a visualisation.

Data Usage

The accessed webpage content is used only to extract words and generate a visualisation in the extension's side panel.

Data Storage

The extension does not store personal data or browsing history.

Data Sharing

The extension does not sell or transfer user data to third parties.

Proxy Service

In some cases, the extension may use a proxy service to retrieve webpage content when direct access is restricted by browser security policies.
